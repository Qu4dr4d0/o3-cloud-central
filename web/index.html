Instalar no pfSense

Copie o comando e execute como root em Diagnostics → Command Prompt no pfSense deste cliente, ou no Shell do console.

O comando baixa o pacote, verifica o download, cadastra este firewall e inicia o serviço. Preserve o comando para você: ele contém um cadastro temporário.

Para desinstalar, use System → Package Manager → Installed Packages no pfSense.
